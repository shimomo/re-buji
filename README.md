# Re:無事（Re:Buji）

地震のあと、従業員に届いたメールに**返信するだけ**で無事を確かめられる、レンタルサーバーに置ける安否確認システムです。気象庁防災情報XML（[jmaxml](https://github.com/shimomo/jmaxml-php)）を使います。**非公式**で、気象庁とは関係ありません。

開発中です。設計は [docs/superpowers/specs/2026-11-05-re-buji-design.md](docs/superpowers/specs/2026-11-05-re-buji-design.md) を参照してください。
