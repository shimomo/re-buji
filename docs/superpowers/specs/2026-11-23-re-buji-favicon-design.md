# ファビコンとアイコン

## ねらい

タイトルなしでブックマークすると、Re:無事 のブックマークがほかのサイトと見分けられない。ファビコンを付けて、16px のアイコンだけで見つけられるようにする。同じ形を、いずれホーム画面などの大きいアイコンにも使う（すぐに使う予定はない）。

## 目標と、しないこと

- 目標：ブックマークバー（明るいテーマ・暗いテーマ）で、16px のアイコンだけで見分けられる
- 目標：`/re-buji/` のようなフォルダに置いた構成でも、ドメインの直下に置いた構成でも、Docker でも出る
- しないこと：PWA の manifest、GitHub のソーシャルプレビュー、README のロゴ、ダークモード用の別の色、`favicon.ico`
- 失敗とみなすこと：16px で「Re」が読めない、見る端末で形が変わる、フォルダに置いた構成でアイコンが出ない

## 案

形は、ブラウザで 4 つの方向を見比べて、作者が C を選んだ（「Re がこのシステムの軸なので」）。

| 方向 | 決め |
|---|---|
| A. 「無」の一文字（青） | 選ばない。16px で画数が多く、つぶれやすい |
| B. チェックの印（緑） | 選ばない。ほかのアプリでもよく見る形 |
| **C. 「Re」の 2 文字（青）** | **作者が選んだ** |
| D. 揺れの線が ✓ になる（緑） | 選ばない。16px で揺れの部分が細かい |

C の中では、コロンを付けない「Re」（C1）を作者が選んだ。コロン付きの「Re:」（C2）は、3 つ並ぶぶん文字が細く小さくなる。

ファイルの置き方は、3 つの案から A を作者が選んだ。

| 案 | 引き換え | 決め |
|---|---|---|
| **A. SVG と PNG を両方置く** | どのブラウザでも出る。PNG を SVG から作る手間がある | **作者が選んだ** |
| B. SVG だけ | ファイル 1 つ。Safari の一部の版と iPhone のホーム画面では出ないことがある | 選ばない |
| C. A に `favicon.ico` を足す | フォルダに置く構成ではドメインの直下の `/favicon.ico` を使えず、`<link>` で指すなら A の PNG と同じ役目 | 選ばない |

## 形

- 青（`--accent`、`#2b6cb0`）の角丸の四角に、白い太線で描いた「Re」。文字はフォントを使わず、線（`path`）で描き込む。作者がブラウザで見た C1 の形（32 の座標で、角丸 7、線の太さ R 3.2・e 2.9）
- `public/assets/` に 3 つのファイルを置く
  - `favicon.svg`：元の絵。大きいアイコンにもこれを使う
  - `favicon-32.png`：32×32。SVG のファビコンを読めないブラウザ向け
  - `apple-touch-icon.png`：180×180。iPhone でホーム画面に追加したとき用。角は丸めない（iPhone が丸める）。地は四角いっぱいの青
- `templates/layout.php` の `<head>` に 3 行足す。どのページ（初期設定とエラーのページも）もこのレイアウトを通る。URL は `app.css` と同じく `$this->url()` で作り、版を `?v=` に付ける
- PNG は SVG から一度だけ作り、リポジトリに入れる。作り直すスクリプトは、zip に入らない `build-files/` に置く
- `public/` の中身が変わるので、出す版のリリースノートの「上げる」に、公開ディレクトリの `assets/` も置き換えることを書く（`bin/upgrade.sh --public` は `assets/` を写す）

## 私が決めたこと（作者が直せる）

- **`<link>` の順は PNG（`sizes="32x32"`）が先、SVG が後**：SVG を読めるブラウザは SVG を選び、読めないブラウザは PNG を使う。外れていたら、一部のブラウザで 32px の PNG がぼやけて見える
- **アイコンの URL に `?v=版` を付ける**：ブラウザはファビコンを長く覚えるので、形を変えたときに入れ替わるように。外れていたら、版を上げるたびにアイコンを 1 度読み直すだけ
- **PNG を作る道具は、作り直すときにだけ `npx` で取る（版を固定）**：手元に SVG を PNG にする道具が無く、zip にもアプリにも依存を足さないため

## 作る人に任せること

- 3 つのファイルとレイアウトを確かめるテストの形（ファイルがあること、PNG の大きさ、SVG に `text` が無いこと、フォルダに置いた構成で URL に基準のパスが付くこと、など）
- PNG を作る道具の選び方（`resvg` など）と、作り直すスクリプトの書き方
- `apple-touch-icon.png` で、文字をどれだけ内側に寄せるか
