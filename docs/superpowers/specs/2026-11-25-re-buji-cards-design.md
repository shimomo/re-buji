# 画面の見た目：中身をどれも白いカードに入れ、縁をはっきりさせ、アイコンを出す

## ねらい

作者は、画面の中身が灰色の地に溶けて見えるのが気になっている。設定画面は白いカード（枠）を使っているので、ほかの画面もそれにそろえて、**全体の統一感**を出したい。あわせて、ファビコンの「Re」のアイコンを画面にも出したい（タブやブックマークと同じ印で、どの画面でも Re:無事 だと分かるように。理由は Claude の読みで、作者は案を選んだ）。

調べると、溶けて見える理由は 2 つあった。

- **中身が地にじか：** ホームの「従業員」「気象庁の情報」「見張り」、従業員・地震・管理者・照合できなかったメールの一覧、CSV の取り込み、代理の記録、DB の更新、設定の「受信の確認」「テストメール」などは、灰色の地に文や表がじかに乗っている（表は、スマホの幅では行ごとにカードになるが、PC の幅では地にじか）
- **カードの縁そのものが弱い：** 地 `#f4f6f8` と白の明るさの差は 1.08:1 で、影も 8% とごく薄い。入力欄とボタンの枠線 `#e3e7eb` は白の上で 1.24:1 で、部品の縁の目安（WCAG 1.4.11 の 3:1）に届かない

## 目標と、しないこと

- 目標：どの画面でも、中身が白いカードの中にあり、カードと入力欄・ボタンの縁が見える
- 目標：どの画面にも「Re」のアイコンが出る。ログインの画面などでは、最初に目に入る大きさで出る
- しないこと：文の書き直し、画面の並びや動きの変更、新しい部品、ダークモード、ナビの形の変更、新しいロゴの絵（ファビコンの絵をそのまま使う）、ヘッダーの名前をリンクにすること
- 失敗とみなすこと：画面によってカードの使い方がばらばらに残ること。カードの中にカードができて、入れ子に見えること。44px のタッチの大きさや、色だけに頼らない知らせ（✕ ⚠ ✓ の印）が崩れること

## 作者が決めたこと

- 中身をカードに入れるだけでなく、縁も強める（2026-11-25）
- 縁は「細い線で区切る」（案 A）。影で浮かせる案 B は選ばない（同日、見本を見比べて）
- 統一感を重視する
- アイコンは「案 2」：ログインした後の画面は、ヘッダーの名前の左に小さく。ログイン・画面の初期設定・エラーの画面は、題の上の中央に大きく（同日、見本を見比べて）

## 作り方の案

| 案 | 引き換え | 決め |
|---|---|---|
| **節ごとのカード** | 各テンプレートの節（見出しとその中身、表、フォーム）を `<section class="card">` で囲む。設定の枠と同じ形になる。テンプレートを広く直す | **選んだ**（作者が選んだ案 2 の作り方として、一つに絞った） |
| ページ全体を 1 枚のカード | `layout.php` だけで済むが、設定の枠がカードの中のカードになり、知らせの箱や数のタイルもカードに入って、形がそろわない | 選ばない |
| CSS だけで表や見出しを白くする | テンプレートを直さずに済むが、見出しとその下の文をひとまとまりにできず、白い所と灰色の所が混じる | 選ばない |

## 形

### 色（`public/assets/app.css` の `:root`）

| 変数 | 今 | 後 | 使う所 |
|---|---|---|---|
| `--bg` | `#f4f6f8` | `#eef1f4` | 地 |
| `--edge`（新しい） | — | `#d5dbe1` | カード、枠（fieldset）、開くもの（details）、数のタイル、知らせの箱の上・右・下、ヘッダーの下線、スマホのナビの上線 |
| `--field`（新しい） | — | `#7d8892` | 入力欄とボタンの枠。白の上で 3.6:1、地の上で 3.2:1 |
| `--shadow` | `0 1px 3px rgba(0,0,0,.08)` | `0 1px 2px rgba(16,24,40,.04)` | カードなどの影（線が主で、影はごく薄く） |
| `--line` | `#e3e7eb` | 今のまま | カードの中の区切り線（表の行、人の行） |

- 色つきの縁は今のまま：`.btn-primary`、`.btn-danger`、知らせの箱の左の太い線、「異常なし」の緑の箱
- 文字の色は変えない。`--muted` は新しい地の上でも 4.8:1、リンクの色は 4.8:1 で、目安（4.5:1）に届く

### カードに入れるもの、入れないもの

- **入れる：** 画面の中身の節。見出し（`<h2>`）があれば、その見出しと、次の見出しまでの文・表・フォームを 1 枚にする。見出しの無い画面は、中身をまとめて 1 枚にする（例：従業員の一覧は、上の操作のリンクと表で 1 枚）
- **入れない（今のまま独立した箱か、地の上）：**
  - 画面の題（`<h1>`）
  - 知らせの箱（`.alert`）と「異常なし」の箱（`.calm`）、数のタイル（`.tiles`）
  - いくつものカードにまたがるフォームの送信ボタン（例：設定の「保存する」）
  - 画面のいちばん下の「戻る」リンク（「一覧へ戻る」「ホームに戻る」など）
- **カードの中のカードを作らない：**
  - 行ごとにカードになる表（`table.stack`）は、カードの中では、スマホの幅でも行を箱にせず、線で区切る
  - カードの中の「開くもの」（`details`。例：「ほか N 人を表示」）は、箱にせず、線で区切る
  - 枠（`fieldset`）はもともとカードなので、さらにカードで囲まない

### 画面ごと

すでにカードの画面（ログイン、画面の初期設定、エラー、「その他」、地震の概要）は、色の変更だけ。

| 画面 | カードにする節 |
|---|---|
| ホーム | 対応中の地震ごとの「⚠ 要確認」「✕ 返信なし」、「従業員」「気象庁の情報」「見張り（状態の URL）」 |
| 地震の一覧 | 表（無いときの文も） |
| 地震の詳しい画面 | 「返信なし」「要確認」「無事」「記録の削除」の各節 |
| 従業員の一覧 | 操作のリンクと表 |
| 従業員の追加・編集 | 枠はそのまま。削除のフォームを 1 枚に |
| CSV の取り込み | 見出しの説明とファイルのフォーム |
| 照合できなかったメール | 説明と表 |
| 管理者 | 説明と表、「管理者を加える」 |
| 代理の記録 | 人と状態、フォーム |
| 訓練 | 説明と枠（枠の外の文を 1 枚に） |
| 設定 | 枠はそのまま。「受信の確認」「テストメール」を 1 枚ずつ |
| DB の更新 | 版と状態、フォーム |

### アイコン

- 絵は `public/assets/favicon.svg` をそのまま使う（`<img>`。URL は `app.css` と同じく `$this->url()` で作り、`?v=版` を付ける）。新しい絵のファイルは足さない
- **ログインした後の画面**（ナビのある画面）：ヘッダーの「Re:無事」の左に、28px のアイコン。間は 8px
- **ナビの無い画面**（ログイン、画面の初期設定、エラー。`layout.php` の `bare`）：今のヘッダー（「Re:無事」の文字と下線）の代わりに、題（`<h1>`）の上の中央に、56px のアイコンと、その下に「Re:無事」（太字）を置く
- アイコンの `alt` は空にする。すぐ横か下に「Re:無事」の文字があり、読み上げで名前が 2 度にならないように

## 制約

- 新しいファイルは足さない（CSS は `public/assets/app.css` だけ、アイコンは今の `favicon.svg`）。PHP の動きは変えない
- 版を上げる。CSS の URL の `?v=` が版なので、上げないとブラウザが古い CSS を使い続ける。`public/assets/app.css` が変わるので、リリースノートの「上げる」に、公開ディレクトリの `app.css` を置き換えることを書く
- 見本：このブレインストーミングで見比べたもの（カードは、今・案 A・案 B を、ホーム・従業員の一覧・設定の一部で並べた。アイコンは、今・案 1・案 2 を、ホームとログインで並べた）。保存はしていない

## 私（Claude）が決めたこと

作者が見ていない細かい点。違っていたら直してください。

1. 入力欄とボタンの枠は、見本の `#87929c` より少し濃い `#7d8892` にした。見本の色は白の上では 3:1 に届くが、地の上の「保存する」などのボタンでは 2.8:1 で、届かなかったため
2. 版は `0.4.4` にする。機能は足さず、見た目だけを直すため
3. 画面のいちばん下の「戻る」リンクと、いくつものカードにまたがる送信ボタンは、カードの外（地の上）に置く。画面の中身ではなく、画面を離れる操作や、画面全体にかかる操作のため
4. カードの中の見出しは、今の `<h2>`（大きさも今のまま）を、カードの最初の行に置く。設定の枠の題（`legend`）と同じく、カードの中の最初の太字になる
5. アイコンの大きさは、ヘッダーで 28px（ヘッダーの高さ 44px に収まる）、ナビの無い画面で 56px にした（見本の大きさ）
6. ナビの無い画面では、小さいヘッダーを残さず、大きいアイコンと名前に置き換えた（見本の案 2 の形）。同じ名前が 2 度並ばないように

## 作る人に任せること

- 各テンプレートの節の切り方の細部（上の表の決まりに沿って）
- カードの中の余白や、見出しの上の間隔の細かい値
- 画面の HTML を見るテストの直し（`<h2>` の前後の形を見ているもの）
- 画面の初期設定で、大きいアイコンと「全 N 段階のうち…」の進み具合の並び
