## Global Constraints

- 計画 1〜12 の Global Constraints をすべて引き継ぐ。主なもの：
  - PHP `^8.3`、SQLite の PRAGMA、UTC の時刻の文字列、名前空間、`.htaccess`
  - `setUp` / `tearDown` を使わない。テストでは、日付に依る値に `FrozenClock` を使う
  - コミットメッセージの末尾に `Co-Authored-By` を付ける
  - Psalm errorLevel 1、Pint
  - `src/php-version.php`、`public/index.php`、`bin/cron.php` は PHP 5.5 以降で読める構文のまま
  - SQL は SQLite と MySQL の両方で動く書き方にする
- DB の形は変えない（マイグレーションを足さない）。v0.1.7 から上げたときに「DB の更新」を押さなくて済むようにするため
- 依存を増やさない。画面に JavaScript を足さない（今の `onsubmit="return confirm(…)"` は使ってよい）
- 画面の文言は、各タスクに書いたとおりにする。今ある文言は変えない

## Review Focus

- 震度がまだ届いていない地域の市町村（`notYetReceived`）→ 今までどおり「○以上の可能性」で、「（地域の震度）」は付けない（Task 1）
- 照合できなかったメールを選んで消すとき、照合したメール（`notification_id` がある）の id が混じる → それは消さない（Task 4）
- 何も選ばずに「選んだメールを消す」を押す → 何も消さず、同じ画面に戻って「メールが選ばれていません。」と出る（Task 4）
- 自動応答のあとに本人の返信が届いた → 答えの欄に本人の返信を出し、自動応答の本文も残る（Task 5）
- 答えの受け渡しで、まとめたままの連絡と取り消された連絡が同じ地震を指している → まとめたままのほうにだけ渡る（Task 2）

### Task 4：照合できなかったメールを、選んで消す

**Files:**
- Modify: `src/Replies/ReplyRepository.php`、`src/Replies/UnmatchedController.php`、`src/Http/AppFactory.php`（ルート）、`templates/mail/unmatched.php`
- Test: `tests/Replies/UnmatchedPageTest.php`

**Interfaces:**
- `ReplyRepository::deleteUnmatchedMany(array $ids): int`（`@param list<int> $ids`）：`notification_id IS NULL` の行だけを消し、消した数を返す。空なら 0（SQL を投げない）。`IN (?, …)` に id を束縛する
- `UnmatchedController::deleteSelected(ServerRequestInterface $request): ResponseInterface`：本文の `ids`（配列）から、数字だけの文字列を int にして集める。`Flash` を constructor に足す
  - 1 件以上消したら、`'N 件のメールの記録を消しました。'` を flash に入れる
  - 何も選ばれていない（`ids` が無いか空）なら、`'メールが選ばれていません。'` を flash に入れる
  - どちらも `/mail/unmatched` へ 302
- ルート：`POST /mail/unmatched/delete` → `deleteSelected`（今の `/mail/unmatched/{id}/delete` は残す）
- テンプレート：
  - 表の前に `<form id="delete-selected" method="post" action="/mail/unmatched/delete" data-confirm="選んだメールの記録を消しますか？" onsubmit="return confirm(this.dataset.confirm)">`（CSRF と「選んだメールを消す」ボタン）
  - 表の見出しの最初に空の列を足し、各行の最初の列に `<input type="checkbox" name="ids[]" value="{id}" form="delete-selected" aria-label="選ぶ">`（行ごとの「消す」フォームは今のまま。チェックボックスは `form` 属性で上のフォームに属する）
  - メールが無いときは、フォームも出さない
