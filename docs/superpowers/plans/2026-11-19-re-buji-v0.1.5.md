## Global Constraints

- 計画 1〜9 の Global Constraints をすべて引き継ぐ。主なもの：
  - PHP `^8.3`、SQLite の PRAGMA、UTC の時刻の文字列、名前空間、`.htaccess`
  - `setUp` / `tearDown` を使わない。テストでは、日付に依る値に `FrozenClock` を使う
  - コミットメッセージの末尾に `Co-Authored-By` を付ける
  - Psalm errorLevel 1、Pint
- DB の形は変えない（マイグレーションを足さない）。v0.1.4 から上げたときに「DB の更新」を押さなくて済むようにするため
- 依存を増やさない
- 画面と案内の文言は、各タスクに書いたとおりにする
- Task 3 の `src/php-version.php`、`public/index.php`、`bin/cron.php` は、ファイル全体が PHP 7.0 以降で構文を読めること（PHP はファイル全体を読んでから動かすので、追い返す相手の PHP で 1 行でも読めないと、案内が出ない）。矢印関数、`?string` などの nullable 型、戻り値の型、名前つき引数、`match`、`never`、型つきのプロパティを使わない。確かめるのは、さくらにある 7.4〜8.2

### Task 1：TLS の理由を、画面でも書いたとおりに出す

**Files:**
- Create: `src/Mail/Imap/StreamWarnings.php`

**Interfaces:**
- `ReBuji\Mail\Imap\StreamWarnings::catch(callable $call): array`（`@template T`、`@param callable(): T $call`、`@return array{T, string}`）：今の `ImapClient::withWarnings()` を移したもの
  - 呼ぶ間だけ `html_errors` を `'0'` にする（`ini_set()` が文字列を返したら、`finally` で元の値に戻す）。PHP は `html_errors` が On だと、エラーハンドラーへ HTML 用に変換した文を渡す（`"` → `&quot;`、`&` → `&amp;`。PHP 8.5 で確かめた）。web の SAPI では既定で On
  - ハンドラーは、どの段階のエラーも true を返して表に出さない（今の `@` と同じ）。理由に使うのは `E_WARNING` だけ
  - 返す理由は最初の `E_WARNING` の文。頭の `関数名(): ` を除き、改行を含む空白の続きを 1 つの空白にする（今と同じ）
- `ImapClient` の文言は変えない
