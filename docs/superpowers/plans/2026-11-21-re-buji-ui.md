# Re:無事 計画 15：画面の見た目と使い勝手（UI/UX）実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 地震のあと、責任者がスマホでホームを開いただけで、どの地震か・誰を確かめればよいかが分かるようにし、全画面を「やわらかい」見た目にそろえる。

**Architecture:** `public/assets/app.css` を 1 枚足して全画面から読み、`layout.php` のインラインの CSS を消す。ナビはスマホでは下のタブ、PC では上の横並び（どちらも同じ HTML を CSS で出し分ける。JS は使わない）。ホームは「対応中の地震」を `EarthquakeRepository::active()` で選び、地震の詳細と同じ `QuakeBoard::build()` と同じ部品のテンプレートで出す。

**Tech Stack:** 計画 14 と同じ（PHP 8.3、Slim、League Plates、PHPUnit、Psalm、Pint）。依存は増やさない。

**Spec:** `docs/superpowers/specs/2026-11-21-re-buji-ui-design.md`（以下「UI 設計」）。元の設計 `docs/superpowers/specs/2026-11-05-re-buji-design.md` の 5.6 も読む。

**前の計画：** `docs/superpowers/plans/2026-11-21-re-buji-v0.1.9.md`（v0.1.9 はリリース済み）。

## Global Constraints

- 計画 1〜14 の Global Constraints をすべて引き継ぐ。主なもの：
  - PHP `^8.3`、名前空間 `ReBuji\`、`.htaccess`
  - `setUp` / `tearDown` を使わない。テストでは、日付に依る値に `FrozenClock` を使う（今は `2026-11-05T03:12:00Z`）
  - コミットメッセージの末尾に `Co-Authored-By` を付ける
  - Psalm errorLevel 1、Pint
  - SQL は SQLite と MySQL の両方で動く書き方にする
- DB の形は変えない（マイグレーションを足さない）
- 外部の CSS・JS・フォント・CDN を読まない。JS のライブラリを足さない。今ある `onsubmit="return confirm(...)"` はそのまま
- `SecurityHeaders` の CSP は変えない
- 画面の文言は変えない。例外は UI 設計 6 章（ホーム）と 6.4（戻り先）、各タスクに書いた文言
- 色は UI 設計 3.2 の表の値を CSS 変数で使う：`--bg #f4f6f8`、`--surface #ffffff`、`--text #26323a`、`--muted #5f6b74`、`--line #e3e7eb`、`--accent #2b6cb0`、`--danger #c0392b`、`--warn #9a5800`、`--ok #237356`
- 色だけで状態を伝えない。警告の帯・タイル・見出しには印（✕ ⚠ ℹ ✓）か文言を必ず添える
- スマホとPC の境目は幅 768px（ナビ）、表をカードにする境目は幅 600px
- 押せるもの（ボタン、タブ、行のリンク、`summary`）は高さ 44px 以上

## Review Focus

- ベースパスの付いた設置（`/re-buji/`、`/re-buji/public/`）→ CSS と全リンクがベースパス付きで出る（Task 1、Task 2）
- 更新待ちの DB → 「DB の更新」の画面でナビの件数を数えず、500 にならず、ログアウトできる（Task 2）
- 対応中の地震で、要確認がすべて確認済み → 要確認のタイルは 0、「うち確認済み n 人」が出て、一覧は空でも見出しは残る（Task 4）
- 返信なしが 21 人以上 → ホームは 20 人と「ほか n 人を表示」、地震の詳細も今と同じく 20 人で切る（Task 3、Task 4）
- `from` に外のサイトの URL や知らない値 → 地震の詳細へ戻り、外へは飛ばない（Task 5）
