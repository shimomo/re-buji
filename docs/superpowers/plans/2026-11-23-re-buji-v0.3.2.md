## Review Focus

- 上げるのが途中で失敗する（置き換え、DB の更新、公開ディレクトリのどれか）→ 前の写しは消さない（Task 1）
- `storage/upgrade-backups/` に、上げるときに作ったものでないもの（ファイル、名前の形が違うフォルダ、シンボリックリンク）がある → 触らない。リンクの先も消さない（Task 1）
- 連絡をまだ 1 通も送っていない地震（保留、送信待ち）→ 照合できなかったメールを数えない（Task 2）
- 最初に送るより前に届いたメール、最後に送ってから 7 日を過ぎて届いたメール、照合できたメール → 数えない（Task 2）
- `html_errors` を切れるとき（cron や、固定していないサーバー）に、理由の中に `&amp;` と書いてある → 戻さずにそのまま出す（Task 3）

### Task 2：地震の画面で、照合できなかったメールを知らせる

**Files:**
- Modify: `src/Replies/ReplyRepository.php`、`src/Quakes/EarthquakesController.php`（`show()`）、`templates/earthquakes/show.php`
- Test: `tests/Replies/ReplyRepositoryTest.php`、`tests/Quakes/QuakeBoardPageTest.php`

**Interfaces:**
- `ReplyRepository::countUnmatchedForQuake(int $earthquakeId): int`
  - その地震の連絡の `MIN(first_sent_at)` から、`MAX(last_sent_at)` の `ReplyMatcher::SENDER_DAYS` 日後まで（両端を含む）に届いた、照合できなかったメール（`notification_id IS NULL`）の数。種類（返信、宛先不明、自動応答など）は問わない。リンク先の照合できなかったメールの一覧と同じにするため
  - 1 通も送っていなければ（`MIN(first_sent_at)` が NULL なら）0
  - 日を足すのは PHP でする（SQLite と MySQL で書き方が違うため）。比べる値は `Time::format()` で作る
- `EarthquakesController::show()`：テンプレートに `'unmatchedMails' => $this->replies->countUnmatchedForQuake($quake->id)` を渡す（`$replies` はもう注入されている）
- `templates/earthquakes/show.php`：`<h2>返信なし（…人）</h2>` のすぐ下に、`$unmatchedMails > 0` で、しかも返信なしの人がいる（`$board['noReply'] !== []`）ときだけ出す。docblock に `/** @var int $unmatchedMails */` を足す

```php

```

**[判断]** 返信なしの人がいなければ出さない。全員の答えがそろった後に出しても、責任者にすることが無いため。数える期間の終わりは、送り主のアドレスで照合する期限（`SENDER_DAYS`、7 日）にそろえる。古い地震の画面で、関係の無い後のメールまで数えないため。
