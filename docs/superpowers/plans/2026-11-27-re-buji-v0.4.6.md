## Global Constraints

- 計画 1〜37 の Global Constraints をすべて引き継ぐ。主なもの：
  - PHP `^8.3`、`setUp` / `tearDown` を使わない、コミットメッセージの末尾に `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`、Psalm errorLevel 1、Pint

- この計画に「」で書いた文は、そのとおりにする。ほかの画面の文は変えない
- **[判断]** crontab に新しい中身を渡しきれなかったら、crontab が入力の終わりを読む前に止める（`proc_terminate()`）。crontab は入力の終わりまで読んでから入れ替えるので、途中までの中身は入らない。理由は「crontab に新しい中身を最後まで渡せなかったので、途中で止めました。」。外れていたら（止める前に crontab が入れ替えていたら）、前と同じく途中までの中身が入る
- **[判断]** エラー出力は、パイプでなく `tmpfile()` の一時ファイルで受ける。`stream_select()` で 3 つのパイプを同時に回すより短く、crontab の出力は小さい。一時ファイルを作れなければ「crontab の出力を受ける一時ファイルを作れません。」で、crontab を使えない理由として出す
- **[判断]** 一時ファイルを作れないとき、`proc_terminate()` が `disable_functions` で止められているときは、そのまま閉じる（落ちない）
- **[判断]** `assets/` のフォルダは、上げるとき（`Upgrade::copy()`）と同じく、`assets/` 自身は 0755、中のフォルダは元のフォルダと同じ権限にする。ファイルは今のまま（元のファイルと同じ権限）
- **[判断]** 写しの名前は `{版}-{年月日-時分秒}`（`UpgradeInstallCommand.php:138`）。消すのは `/\A\d+\.\d+\.\d+-\d{8}-\d{6}\z/` に合うものだけ。版にほかの形（`0.5.0-rc.1` など）を使うと、その写しは自動では消えない（安全な側）。今のタグはすべて `X.Y.Z`
- **[判断]** 答えのファイルがあるのに読めなければ、待つのをやめる。ファイルは一時ファイルに書いてから名前を変えて置く（`ProbeVisit::record()`）ので、書きかけを読むことは無い。読めないのは権限のためで、待っても変わらない
- **[判断]** 手順書の FTP の節の例のフォルダは、さくらの公開ディレクトリの `www/` にする（今は `public_html/`）。`docs/upgrade.md` の `--public ~/public_html/anpi` の例（2 か所）も、README と同じ `~/www/anpi` にそろえる。「ロリポップのように、」は消す。cron の節のロリポップの項目は、さくらの管理画面の項目に置き換える。ほかの節（`docs/usage.md` の 1 時間の上限の例など）のロリポップの名前は、この計画では触らない
- **[判断]** さくらの管理画面での「分」の書き方（`*/2`）は、作者が管理画面で確かめる（PR の確認の項目に入れる）。ヘルプのページには、間隔の書き方の例が無い

#[Test]
public function takesALongErrorOutputWithoutWaiting(): void
{
    // The child writes 200,000 bytes of errors without blocking and gives up after 3 seconds if nobody reads them.
    $code = <<<'PHP'
        stream_set_blocking(STDERR, false);
        $left = str_repeat('e', 200000);
        $until = microtime(true) + 3;
        while ($left !== '' && microtime(true) < $until) {
            $written = (int) fwrite(STDERR, $left);
            $left = substr($left, $written);
            if ($written === 0) {
                usleep(10000);
            }
        }
        echo $left === '' ? 'all' : 'stuck';
        PHP;

    [$status, $output, $error] = Crontab::runCommand([PHP_BINARY, '-n', '-r', $code], '');

    self::assertSame([0, 'all', 200000], [$status, $output, strlen($error)]);
}

#[Test]
public function stopsACommandThatDoesNotTakeTheWholeInput(): void
{
    // Like a crontab that would install what it has read: it stops reading, and would go on to install a second later.
    $code = 'fread(STDIN, 10); fclose(STDIN); sleep(1); echo "installed";';

    [$status, $output, $error] = Crontab::runCommand([PHP_BINARY, '-n', '-r', $code], str_repeat("x\n", 500000));

    self::assertSame([1, '', 'crontab に新しい中身を最後まで渡せなかったので、途中で止めました。'], [$status, $output, $error]);
}
