# 気象庁のサンプル電文

このディレクトリには、気象庁が公開している「気象庁防災情報XMLフォーマット」のサンプルデータのうち、テストで使う 13 ファイルを、配布物のまま（無加工で）置いています。

出典：[気象庁ホームページ](https://xml.kishou.go.jp/)

利用にあたっては、気象庁ホームページの利用規約（政府標準利用規約（第2.0版）準拠）に従います。

|---|---|---|
| サンプルデータ（xml） | 2026-09-17 | https://xml.kishou.go.jp/jmaxml_20260917_Samples.zip |

| 地震 | ファイル |
|---|---|
| 駿河湾（2009-08-11、最大震度 6 弱） | `32-35_07_01_100915_VXSE51.xml`、`32-35_07_05_100915_VXSE51.xml`、`32-35_07_06_240613_VXSE53.xml` |
| 取り消された地震（2008-06-14） | `32-35_06_01_240613_VXSE52.xml`〜`32-35_06_06_100915_VXSE53.xml` |
| 近い時間の 2 つの地震（2010-07-05） | `32-35_08_01_100915_VXSE51.xml`、`32-35_08_03_100915_VXSE51.xml`、`32-35_08_05_100915_VXSE51.xml`（地震 A）、`32-35_08_02_100915_VXSE51.xml`（地震 B） |

サンプルの地震は過去のものなので、テストでは時計を地震の直後に止めて使います。
